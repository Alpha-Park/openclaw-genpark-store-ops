# genpark-store-ops

## Overview
This skill is tailored for Direct-to-Consumer e-commerce. It assists users in setting up standard Shopify themes, structuring high-conversion product listings, and optimizing store operations.

## Capabilities
1. **Product Listings**: Generate SEO-friendly, persuasive product descriptions from raw product specifications.
2. **Store Layout Advice**: Recommend layout changes for homepage and product detail pages to increase conversion rates.
3. **Inventory Operations**: Establish workflows for tracking stock and handling low-inventory alerts.

## Usage Instructions
If the user wants to launch a product:
- Ask about the primary platform (e.g., Shopify).
- Propose a standard listing structure: Hook -> Key Benefits -> Technical Details -> FAQ.
- Provide step-by-step guidance on setting up shipping zones and basic store settings.
